# E009 CPU voltage test

200/400 MHz target: **1.0500 V → 1.0375 V**. CPU/GPU clocks, higher CPU voltage corners and CPR stay available as before. This is a stability experiment; battery gains are unmeasured.

1. In TWRP, install `Download/E009-update.zip` over E008 without wiping Data.
2. Reboot Android and allow five minutes for startup tuning. Magisk is retained.
3. Try ordinary app use and several screen-off/wake cycles. Report freezes, reboots or unusual app crashes. Avoid important file writes during the first brief check.

Kernel version should contain `E009-g48ba363d`; the ROM label stays E007. GPU wake remains 310 MHz. Data barriers and eMMC cache are unchanged.

If unstable: TWRP → Install → Install Image → `Download/E008-boot.img` → **Boot**, then reboot. That image retains Magisk. The older E008 ZIP checks its own original base, so use the boot image for this fallback.
