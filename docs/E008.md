# E008 kernel test

Includes: opt-in routine SMEM logging, on-demand SMEM snapshots, 128 KiB/CPU trace default, less compression timing work, independent eMMC/SD pressure, signed I/O prediction and GPU cap rounding.

1. Reboot into TWRP and install `Download/E008-update.zip` over E007.
2. Do not wipe Data. Reboot Android and allow five minutes for existing startup tuning.
3. Try Home/scrolling/app switching, a file copy on internal/SD storage, and a call/text/mobile-data check.

Magisk, the installed ramdisk and the separate display/device tree are retained. The installer rejects a changed boot; repackage if you alter Magisk before installing. Android's ROM label stays E007; `adb shell uname -r` should contain `E008-gf1a2630c`.

No undervolt or new GPU step is included. GPU wake stays 310 MHz in Balanced/Power Save. Data barriers and the eMMC cache are unchanged. Battery gains are unmeasured.
