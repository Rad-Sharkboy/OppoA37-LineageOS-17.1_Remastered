# E007 combined device test

Includes the retained E001–E005/V2.1 kernel work, six independent kernel fixes, 200 MHz wake in Balanced/Power Save, and a responsive legacy path for Power Save. Performance keeps its high CPU/GPU active floors. No extra undervolt, new GPU step, storage clock change, or radio/wakelock modification is included.

Local validation: all five changed kernel objects and the full GCC 4.9 ARM64 Image.gz-dtb build passed. Extracted functions passed ASan/UBSan: 983,040 CPU cases, 343 GPU limit cases, FIFO/read batching in both timestamp formats, OPPO error/zero/RTC tests, and VM-BMS fallback tests. Original functions fail the relevant regressions. The rebuilt AArch64 HAL passed 171 emulated policy/ABI/error/callback/shell cases, including the actual original override's legacy perfd path. Hardware results and battery-runtime gains remain unmeasured.

The original image has no vm_bms executable in either bin location, although init declares it. E007 repairs kernel fallback; a compatible daemon has not been restored. The offline charger contains Android Health 2.0/BatteryMonitor capacity-path logic; the Android wrapper and VM-BMS paths are repaired, but the reported 90%/49% discrepancy still needs a charging/reboot check. Voltage-derived SOC and estimated current are not calibration.

A 294.912 MHz GPU generator entry exists, but shares the 310 MHz voltage tier; TZ/DT integration and phone behavior remain untested. The CPU DT has −50 mV initial offsets at corners 3–8, with 12.5 mV regulator steps; this is not proof of a constant live −50 mV. Additional undervolting and GPS/cellular drain diagnosis need device evidence. Shared supplies remain unchanged.

Build with tools/build_e007.py, using the pinned original V2 ZIP/system image, the exact new raw Image, a clean kernel source checkout and --kernel-source. Existing V2.1 pins/download branch are retained. The full OTA preserves original Android file metadata and the boot header/ramdisk/separate QCDT; only the kernel and reviewed system files change.

Installation and Windows checks are in the GitHub downloads/E007 folder on e007-download. Flash the full ZIP in TWRP without wiping Data. Keep V2.1 available; reinstall Magisk if root is wanted. Check first touch/scrolling, profile switching and wake, charging/reboot SOC, saving/internal+SD copy hashes, camera, calls/SMS/IMS/data and 65 Hz. Stability feedback is sufficient for an initial test; percentage movement alone does not prove battery gains.

Device follow-up on V2.1: the system-user HAL could not write root-owned 0644 hispeed_freq/target_loads. Granting system ownership and 0664 changed profile_apply from incomplete to ok after screen wake. E007 grants access after selecting interactive and again during one-time reconciliation; no voltage change was involved.
