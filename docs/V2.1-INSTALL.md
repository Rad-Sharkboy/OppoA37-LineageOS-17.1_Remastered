# V2.1 combined test ROM

[Download V2.1](https://github.com/Rad-Sharkboy/OppoA37-LineageOS-17.1_Remastered/raw/refs/heads/v2.1-download/downloads/V2.1/Lineage_17.1_REMASTERED_V2.1.zip)

For Oppo A37/A37f/A37fw running the existing V2. This is the combined device-test release: E001–E005, native Balanced/Performance switching, E006 and the kernel fixes/debloat are included automatically. No ADB tuning scripts or Magisk profile module are needed.

## Install

1. Download the ZIP to the phone/SD card and keep the original V2 ZIP available. In TWRP, back up Boot, System and Data before the first test.
2. Flash V2.1 over V2. **Do not wipe or format Data.** The installer replaces System and Boot, preserving installed apps and user data. It disables only the recognized old A37 profile module and backs up the recognized E002 startup helper so they cannot fight the integrated settings.
3. Reboot and allow the first boot to finish. Use the phone normally; its one-time profile reconciliation runs five minutes after boot completion. Balanced retains the battery settings; Performance requests high active CPU/GPU minimums while thermal protection and hardware sleep remain.
4. The included boot image uses the original V2 ramdisk. If your current boot is Magisk-patched, reinstall Magisk after flashing if you want root. The ROM tuning itself does not require Magisk. System add-ons installed outside the V2 ZIP may also need reinstalling after System replacement.

Like the original V2 ZIP, this package does not carry a recovery ZIP signature; use TWRP's normal custom-ROM installation with ZIP signature verification off. The download folder's SHA256SUMS verifies the downloaded file. The installer checks device/partition capacities, verifies the embedded boot hash, writes only the expected boot partition and compares the readback.

## Quick check

Try first touch/Home after a pause, scrolling, app switching, camera, audio, Wi-Fi, a call and mobile data. Save/reopen a photo or document and copy a familiar file to internal/SD storage. Switch Performance → Balanced, then do one normal reboot. Report any new delay, freeze, visual fault, restart or save stall; no timed battery benchmark is required.

The kernel restores real fsync completion instead of reporting success while bypassing the save; saves can take longer than that old shortcut. The 65 Hz display configuration, CPU/GPU overclocks, original ramdisk/DT and telephony components are retained. [E006-KERNEL-WORK.md](E006-KERNEL-WORK.md) records source changes and local checks; hardware behavior is the purpose of this test release.

If it does not boot or behaves badly, return to TWRP and restore the Boot/System backup. Restoring the original V2 ZIP also restores its System/Boot without formatting Data; reinstall system add-ons/root as needed. The old E002 helper backup, when present, is under `/data/adb/a37-v21-backup`; the old module is disabled rather than deleted.

## Build provenance

`tools/build_v21.py` starts from the pinned V2 ZIP/system image, replaces only the selected files while restoring Android ownership, permissions, timestamps and extended attributes, repairs the inherited inode-bitmap padding error, and builds a full block OTA. It retains the original boot header/address layout, ramdisk and QCDT while replacing the raw kernel and updating its boot ID. The new kernel source commit is `ea245232f6d`.

The native Power HAL patch is the same pinned extension documented in `tools/power-profile-bridge/README.md`. A root oneshot init service handles the old delayed kernel tuning and then exits. Runtime code has no ongoing shell polling loop. Development notes and test harnesses are excluded from the flashable ZIP.

The download folder includes `build-manifest.json` with component hashes, edited-file metadata and the exact ROM source commit. The ZIP build uses Brotli quality 9 with a standard 24-bit window, then stores that compressed payload directly in the ZIP. APKs, camera modifications and other unchanged file contents are retained from V2.
