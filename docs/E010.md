# E010 active CPU voltage test

New floors: 533/800 MHz **1.0500→1.0375 V**; 998 MHz **1.1625→1.1500 V**. CPR can still raise voltage when needed. These are lower limits, not a promise that every workload runs at that voltage. 200/400 MHz retain E009. Maximum clocks are retained.

1. TWRP → install `Download/E010-update.zip` over E009, without wiping Data.
2. Reboot and allow five minutes. Magisk is retained; kernel version contains `E010-g21e86f7d`.
3. Try normal apps and several sleep/wake cycles. Report reboots/freezes or unusual crashes.

This kernel also adds a read-only CPR corner table and root-only, bounded target trims. Additional trims default to zero and reset on reboot; further high-frequency tests will use these controls after checking the new floors. Target counts are not calibrated millivolts.

If unstable: TWRP → Install Image → `Download/E009-boot.img` → **Boot**. ROM label stays E007. GPU wake stays310 MHz; Data barriers/cache stay unchanged. Battery savings remain unmeasured.
